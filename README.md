# NÛR (نور) — Maquette interactive

Maquette Streamlit de l'application islamique NÛR : apprendre, réciter, méditer, aimer.

**Statut : maquette de démonstration.** Les contenus coraniques, translittérations, traductions et notes de tajwid sont des données de démonstration, non validées par l'imam garant. Les horaires de prière sont fictifs. Aucune publicité, aucune représentation d'être vivant.

## Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publier un lien public (sans code pour le visiteur)

1. Se connecter sur https://share.streamlit.io avec le compte GitHub.
2. « Create app » puis sélectionner ce dépôt, branche `main`, fichier `app.py`.
3. Valider : Streamlit génère le lien public.

## Limites connues

Application web : pas de mode hors ligne, pas de publication dans les boutiques d'applications, pas de géolocalisation réelle.
